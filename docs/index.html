Conectar ao GitHub (uma vez só)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories e marque só este repositório.
  3. Em Permissions → Repository permissions, deixe Actions em Read and write e também Contents em Read and write (este serve para salvar a lista de filmes).
  4. Gere o token, copie e cole abaixo. Ele fica salvo só neste navegador.

Já tem um token só com Actions? Em github.com/settings/personal-access-tokens, abra-o, clique em Edit, adicione Contents: Read and write e Update. O valor do token continua o mesmo.
